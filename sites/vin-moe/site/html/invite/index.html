keeping it private

  • The link is the invite: the session id and password are worked out from its code, so anyone with the link can join the session and read along. Send it only over something private, and only to the people you mean. When they join, compare verify codes with them (:verify NICK) over something else, a call or in person.
  • A random code is made here, in your browser, with its secure random numbers. One of your own is your session id and password, encoded, not encrypted. This page can't reach any server, and leaving it wipes the code.
  • Nothing is stored. There's no list of invites to look up or find: the server works out the session from the code each time the runner is downloaded, puts it into the same script as chat.vin.moe, and forgets it. Invite links are left out of every access log and trace, and are never cached.
  • Opened in a browser, or by a chat app making a preview, the link comes here, with the code after the #, which browsers never send to a server. The code is then taken out of the address bar.
  • The command starts with a space, which keeps it out of your history in fish, in bash with HISTCONTROL=ignorespace (the default on Debian and Ubuntu) and in zsh with setopt HIST_IGNORE_SPACE. PowerShell keeps it in its history.
  • A copied command stays on your clipboard, and in any clipboard history, until something else replaces it.
