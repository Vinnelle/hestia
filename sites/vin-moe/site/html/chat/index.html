chat

Private group chat for the terminal.

No server, no accounts, and nothing left behind. Share a session id and a password, and everyone with both is in.

why chat

Everything a group chat needs, and nothing that knows who you are.

  • No server in the middle

    Peers find each other over the BitTorrent DHT and talk directly. There's no account to make and no server keeping your messages.

  • Post-quantum encryption

    X25519 and ML-KEM-768 agree the keys together, and every message is sealed with XChaCha20-Poly1305. The key moves on with each one, so a stolen key can't read what came before.

  • Gets through NATs

    chat asks your router to open a port. When direct UDP still can't get through, public Nostr relays carry the traffic, sealed so they can't read it or tell who it's for.

  • Tor, built in

    One setting sends everything through onion services instead, and Tor and DHT members can still share a room.

  • Quiet on the wire

    Every packet is the same size and goes out on a steady beat, with or without anything to send, so the traffic doesn't show when anyone typed.

  • Nothing left behind

    No history, no logs and no install. Nothing touches the disk unless you save your settings, and those are sealed under a passphrase.

  • Files and pictures

    Send a file to the room, or see a picture right in the terminal. Each one is checked against its hash before it's kept.

  • Made for the terminal

    Vim-style keys, your terminal's own colours, and a plain line mode for scripts and pipes.

how it works

A room is an id and a password. That's the whole sign-up.

  1. Start a session

    Press Ctrl+N. chat makes up a session id and asks you for a password.

  2. Share both

    Send them to whoever you want in. They press Ctrl+J and type both. Nobody without both can find the room, let alone read it.

  3. Compare codes

    When someone joins, chat shows a verify code. Read it to each other on a call or in person. If it matches, nobody is sitting in the middle.

under the hood

Key agreement
X25519 and ML-KEM-768, together
Encryption
XChaCha20-Poly1305, with a new key for every message
Identity
Optional Ed25519 signing keys, as AGE or PGP
Finding peers
BitTorrent DHT over IPv4 and IPv6, and LAN broadcast
Getting through
Router port mapping (PCP, NAT-PMP, UPnP), then Nostr relays
Anonymity
Tor onion services, through a running tor or chat's own
On the wire
1004-byte packets, one every 1.5 to 1.9 seconds per peer
Saved settings
Sealed with Argon2id and XChaCha20-Poly1305, and can also need the device's TPM, a FIDO2 key or an authenticator code
Updates
Signed offline with minisign, and checked before they install
Platforms
Linux and Windows, x86_64
Built with
C, with libsodium, liboqs, Mbed TLS and libsecp256k1 linked in statically
Licence
GPL-3.0

questions

Has it been audited?

No. It's built on well-reviewed libraries, libsodium and liboqs, but chat itself hasn't been independently audited.

Does it keep my messages?

No. Messages are on screen while the session is open and gone when it closes. Saving your settings never includes them.

Who can see that I'm using it?

Your network sees your peers' addresses and a steady stream of same-size packets, which someone determined could recognise as chat. In Tor mode it only sees Tor. To anyone outside the room, the packets themselves are random bytes.

What if someone else gets the id and password?

They can join, and they show up in the peer list unverified. Set Compare verify codes to required, and nothing you send reaches anyone until you've compared codes with them.

Why isn't it in my package manager?

On purpose. A package manager keeps a record of what's installed, and chat tries to leave nothing behind. It's one file you can put anywhere, or run with the command below and not keep at all.

Does it run on macOS or phones?

No. Release builds are for Linux and Windows on x86_64.

get chat

One command, and nothing to install.

I know some people distrust and dislike these curl installations, so you can download the binary here, and below you can see the contents of the install script, as well as its SHA.

curl -fsSL https://chat.vin.moe | sh

Paste it into bash, zsh, fish or any other shell. It pipes into sh, so the shell you type it in doesn't matter, and it works from Git Bash on Windows too. It needs curl, and minisign or OpenSSL 3 to check the release signature. Options for chat go after sh -s --, as in sh -s -- --routing tor.

the script

It's less of an install script, and more a runner. It downloads the latest release into a private temporary folder, checks SHA256SUMS against chat's release key, checks the binary against SHA256SUMS, runs it, and deletes it again when chat exits. Nothing is installed, and nothing is left behind.

SHA-256 @@sha256:chat.sh@@

@@script:chat.sh@@

To check it before running anything, curl -fsSL https://chat.vin.moe | sha256sum prints the same SHA-256. Browsers get the same file at chat.vin.moe/chat.sh.

by hand

Download chat-linux-x86_64, SHA256SUMS and SHA256SUMS.minisig from the latest release. Check the signature, then the binary, and put chat wherever you like:

minisign -Vm SHA256SUMS -P RWSR+ZdG2DibcI2waaAukeezQJcX5D5BcYHmZ2lOzLVATd2FnlS7YEZB
sha256sum -c --ignore-missing SHA256SUMS
install -Dm755 chat-linux-x86_64 ~/.local/bin/chat
irm https://chat.vin.moe | iex

Paste it into PowerShell: Windows PowerShell 5.1, which comes with Windows, or PowerShell 7. It needs nothing else. Windows has no built-in way to check the release signature, so the script carries its own Ed25519 and BLAKE2b check, which PowerShell compiles as it runs.

minisign -Vm SHA256SUMS -P RWSR+ZdG2DibcI2waaAukeezQJcX5D5BcYHmZ2lOzLVATd2FnlS7YEZB
